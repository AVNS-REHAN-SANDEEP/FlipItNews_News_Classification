# FlipItNews_News_Classification 

Problem
FlipItNews (an Indian startup) wants to automate news categorization to improve content
organization, search, and personalized news delivery. Manually labeling thousands of
news articles requires time and effort. An NLP classification system can predict a
category from an article's text and help streamline the publishing workflow.

Dataset
Dataset located at:
https://drive.google.com/uc?id=1POmzYEQZgZVqJO3F_cyNcd4QmoNE_mCv
Task:
 Perform exploratory data analysis (EDA) to examine the dataset, identify missing
values, and visualize the distribution of news categories.
 Preprocess the text by converting it to lowercase, removing punctuation and stop
words, and performing tokenization.
 Extract numerical text features using Bag of Words, TF-IDF, and Word2Vec, and
develop Neural Network (NN) and Recurrent Neural Network (RNN) models for
news classification.
 Compare model performance using accuracy, precision, recall, and F1-score, and
evaluate how automated news categorization can improve FlipItNews’ content
organization and personalized news delivery.
 Design and develop an interactive web-based dashboard to deploy and host the
trained RNN model for automated news classification
